Where is my data stored?

Current mode:

Once you configure Supabase, everyone using this deployed site — on any laptop, phone, or tablet — sees the same live data. It syncs in real time.

How to enable shared cross-device data (one-time, ~5 minutes):
1. Create a free project at supabase.com.
2. Open the SQL Editor and paste + run:
CREATE TABLE IF NOT EXISTS hg_state ( id integer PRIMARY KEY, data jsonb NOT NULL DEFAULT '{}', updated timestamptz DEFAULT now() ); INSERT INTO hg_state (id, data) VALUES (1, '{}') ON CONFLICT DO NOTHING; ALTER TABLE hg_state DISABLE ROW LEVEL SECURITY; ALTER PUBLICATION supabase_realtime ADD TABLE hg_state; 3. In Supabase → Settings → API, copy your Project URL and anon public key.
4. Open index.html, find the block near the top of the <script> that reads
var HG_SUPABASE_URL = ''; var HG_SUPABASE_KEY = '';
and paste your values in the quotes.
5. Commit + push to GitHub — Vercel redeploys automatically. Everyone sees shared, live data.
Local mode (default): data is saved in this browser only (key hg_helpdesk_v1). Fine for testing on one machine, but nothing syncs between devices.
