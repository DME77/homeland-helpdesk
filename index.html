Import users from CSV

Upload a CSV file to create many users at once. Column order (first row must be the header):

Name,Username,Password,Role,Department,ManagerUsername
Field rules:
• Role must be one of: superadmin, manager, or user
• Department must match an existing department (see Settings → Departments)
• ManagerUsername is required only for role=user, and must be an existing manager's username. Leave blank otherwise.
